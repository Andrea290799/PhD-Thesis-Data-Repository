- **Supplementary Table 3.1**: Summary of the 138 included articles, including all extracted data and manual annotations
- **Supplementary Table 3.2**: Molecules identified in the scoping analysis (_n_ = 451). 
- **Supplementary Table 3.3**: Molecule occurrence across the 138 selected articles. 
- **Supplementary Table 3.4**: Reactome enrichment analysis results. For each enriched Reactome pathway, the table specifies the pathway identifier and description (ID/Description). The magnitude of enrichment is detailed through the GeneRatio, background ratio (BgRatio), RichFactor, FoldEnrichment, and zScore metrics. Statistical significance is defined by the raw _p_-value, Benjamini-Hochberg adjusted _p_-value (p.adjust), and q-value. The table also lists the total number of involved molecules (Gene Number) and their specific symbols (geneID). Top-level pathways are also annotated (Parent Pathway). Results are sorted by adjusted _p_-value.
