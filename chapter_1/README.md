# Chapter 1

- **Supplementary Table 1.1 (_patients.csv_): Subject clinical information**. Group abbreviations: C, control; M, mild; SU, severe uncontrolled. Medication and clinical variables abbreviations: AC, anticholinergic;  AH, antihistaminic; BMI, Body Mass Index; ICS/LABA, inhaled corticosteroids combined with long-acting beta-adrenoceptor agonist; LTRA, antileukotriene; OCS, oral  corticosteroids; SABA, short-acting beta adrenoceptor agonist; T, theophylline; TCS,  topic corticosteroids; U, ISAC units. Mites abreviations: A. siro, _Acarus siro_; B. tro, _Blomia tropicalis_; D. far, _Dermatophagoides farinae_; L. epi, _Lepidoglypus destructor_; D. pte, _Dermatophagoides pteronyssinus_; T. put, _Tyrophagus putrescentiae_. 

- **Supplementary Table 1.2 (_de_mirnas.csv_): Differentially expressed miRNAs in SU vs. M comparison**. Table includes _p_-adjujsted values and log<sub>2</sub> transformed group mean expression fold change, Log<sub>2</sub>(FC).
- **Supplementary Table 1.3 (_de_mirnas_m_su_exp.csv_): Differentially expressed miRNA normalized expression values (2<sup>-ΔΔCt</sup>).** Associated with Figure 1.1.
- **Supplementary Table 1.4 (_enrichment.csv_): Results of functional enrichment analysis of Gene Ontology Biological Process (over representation analysis, ORA) of the 40 differentially expressed miRNAs between the severe uncontrolled and mild patient groups**. Only GO terms with Benjamini-Hochberg p-_adjusted_ value < 0.05 with more than 4 associated DEMs are displayed and considered enriched. Associated with Figure 1.2.
- **Supplementary Table 1.5 (_metabolites.csv_): Key allergic asthma severity related metabolites (https://doi.org/10.1111/all.15192) abundances in serum**.
- **Supplementary Table 1.6 (_corr_rho.csv_): Spearman ρ values from correlation analysis between key allergic asthma severity related metabolites (https://doi.org/10.1111/all.15192) abundances and differentially expressed miRNAs expression levels**. 
- **Supplementary Table 1.7 (_corr_pval.csv_): _p_-values from correlation analysis between key allergic asthma severity related metabolites (https://doi.org/10.1111/all.15192) abundances and differentially expressed miRNAs expression levels**.
- **Supplementary Table 1.8 (_targets.csv_): Metabolism-directed filtered miRNA-validated-target list**. 
- **Supplementary Table 1.9 (_validation.csv_): Validation results in CAMP cohort**. Validated miRNAs by RNA-seq, their basemean, log<sub>2</sub>(FC) and _p_-value are shown for each extreme comparative of patients in CAMP cohort.
