- **Supplementary Table 1.1 (_patients.csv_): Subject clinical information**. Abbreviations: C, control; M, mild; SU, severe uncontrolled; AC, anticholinergic;  AH, antihistaminic; BMI, Body Mass Index; ICS/LABA, inhaled corticosteroids combined with long-acting beta-adrenoceptor agonist; LTRA, antileukotriene; OCS, oral  corticosteroids; SABA, short-acting beta adrenoceptor agonist; T, theophylline; TCS,  topic corticosteroids; U, ISAC units.
- **Supplementary Table 1.2 (_de_mirnas.csv_): Differentially expressed miRNAs in SU vs. M comparison**. Table includes _p_-adjujsted values and log<sub>2</sub> transformed group mean expression fold change, Log<sub>2</sub>(FC).
- **Supplementary Table 1.3 (_de_mirnas_m_su_exp.csv_): Differentially expressed miRNA normalized expression values (2<sup>-ΔΔCt</sup>).** 
- **Supplementary Table 1.4 (_enrichment.csv_): Results of functional enrichment analysis of Gene Ontology Biological Process (over representation analysis, ORA) of the 40 differentially expressed miRNAs between the severe uncontrolled and mild patient groups**. Only GO terms with Benjamini-Hochberg p-_adjusted_ value < 0.05 with more than 4 associated DEMs are displayed and considered enriched.

- **Supplementary Table 1.6 (_corr_rho.csv_): Correlation analysis between key allergic asthma severity related metabolites (https://doi.org/10.1111/all.15192) abundances and differentially expressed miRNAs expression levels**. Spearman  \rho
