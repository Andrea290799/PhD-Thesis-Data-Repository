# PhD-Thesis-Data-Repository

# Chapter 2
- **Supplementary Table 2.1 (_patients.csv_)**: Subject information.
-  **Supplementary Table 2.2 (_rna_statistics.csv_)**: Patient clinical characteristics for small RNA-seq. 
- **Supplementary Table 2.3 (_prot_statistics.csv_)**: Patient clinical characteristics for proteomics analysis.
- **Supplementary Table 2.4 (_degs.csv_)**: Summary of differentially expressed miRNAs (DEMs) in PL-EVs across the three experimental comparisons.
- **Supplementary Table 2.5 (_deps.csv_)**: Summary of differentially expressed proteins (DEPs) in PL-EVs across the three experimental comparisons.
- **Supplementary Table 2.6 (_correlations.csv_)**: Summary of Spearman correlated miRNAs and proteins in PL-EVs across different allergic severity grades.
- **Supplementary Table 2.7 (_indiv_enrichment.csv_)**: Functional ORA enrichment results for PL-EV differentially expressed molecules.
- **Supplementary Table 2.8 (_joint_enrichment.csv_)**: Results of the joint miRNA-protein functional ORA enrichment analysis. 
- **Supplementary Table 2.9 (_go_gsea_mirnas.csv_)**: GO term GSEA of miRNAs in PL-EVs.
- **Supplementary Table 2.10 (_gsea_reg_hubs.csv_)**: GSEA of miRNA regulatory targets in PL-EVs.
- **Supplementary Table 2.11 (_ora_reg_hubs.csv_)**: ORA of regulated miRNA targets in PL-EVs. 
- **Supplementary Table 2.12 (_go_gsea_mirnas_filt.csv_)**: Subset of Supplementary Table 6 used for figure representation.
- **Supplementary Table 2.13 (_gsea_reg_hubs_filt.csv_)**: Subset of Supplementary Table 7 used for figure representation.
- **Supplementary Table 2.14 (_ora_reg_hubs_filt.csv_)**: Subset of Supplementary Table 8 used for figure representation.


# Chapter 3

- **Supplementary Table 3.1 (_mactool_papers.csv_)**: Summary of the 138 included articles, including all extracted data and manual annotations
- **Supplementary Table 3.2 (_mactool_molecules.csv_)**: Molecules identified in the scoping review (_n_ = 451). 
- **Supplementary Table 3.3 (_mactool_molecules_ocurrence.csv_)**: Molecule occurrence across the 138 selected articles. 
- **Supplementary Table 3.4 (_mactool_pathways.csv_)**: Reactome enrichment analysis results.
